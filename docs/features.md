# Available upstream features

The maximum preset exposes all **80 skills** below. The default installs only the Duet manager. Upstream experimental skills and workflows requiring other accounts remain explicit choices when invoked. See [native integration setup](integrations.md).

| Source | Skills | Application |
| --- | ---: | --- |
| Matt | 38 | Native plugin; 27 standard plus 11 miscellaneous/in-progress |
| Superpowers | 15 | Native plugin; exact-pin existing Claude installation may be reused |
| claude-mem | 27 | Native plugin plus shared local worker, MCP and viewer |

Runtime capabilities include automatic observation capture, summaries, startup/prompt/file context, SQLite and semantic search, timeline/detail retrieval, manual memory saves, code structure search, work state, custom modes, corpus build/prime/query, and a local viewer. Cloud sync and third-party desktop/reporting services need their own accounts/apps. No external release or message is sent merely by installing.
